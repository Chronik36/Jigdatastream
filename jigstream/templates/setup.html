To add an inbox, Gmail needs an app password, a 16-letter code that lets this app read mail (read-only) without your real password:

  1. Turn on 2-Step Verification for the account, if it isn't already.
  2. Open App passwords, type a name like "Order tracker", and press Create.
  3. Paste the 16-letter code below. Repeat for each inbox.

The password is checked with Gmail, then saved only on this Mac. Your mail never leaves this computer.
