Live package tracking

Every 3 hours BotTrack checks each open USPS, UPS and FedEx package and moves it to In transit, Out for delivery or Delivered. No keys needed: it opens the carrier's normal tracking page in a hidden window on this Mac and reads the status, slowly and one page at a time. If a carrier shows a robot check, that package keeps the status from your emails. {% if tracking.last %}

Training mode

For improving the AI. Each order on the Orders page has a status dropdown (on unless you switch it off here). Setting the right status searches your inboxes for that order's emails, re-reads them, and saves the matching ones as examples (see them here). The examples are shown to the model before each new email, so it learns how your retailers word things. Example emails are stored on this Mac.
